# Для самостоятельного изучения С++ была создана директория embedded-cpp

**Глобальная цель:** Изучить C++ в концепции "C с классами" для перехода в embedded-разработку и получения должности инженера-программиста микроконтроллеров /
 встроенных систем.

**Вектор развития на С++:**

* Структуры. 
* Классы. 
* Объединение. 
* Ссылки. 
* Указатели.
* Чем отличается ссылка от указателя.


**Изучал на Си:**

* Биты, байты, циклы, условия, сдвиги, маски, логические элементы.
* Массивы, переменные, указатели.
* Практический опыт: разработка парсера CAN-шины. 

**Окружение и инструменты:**

* Операционная система: Linux\Mint Android\Termux
* Редактор кода: Neovim (с low-level плагинами)
* Компилятор: G++ (для проверки логики)
